# my-standards

A personal Claude Code plugin containing my coding standards and conventions. Install it to give Claude context on how I structure projects — where files live, naming rules, error handling patterns, response shapes, and what must be in place before committing.

## Skills

| Skill | Trigger |
|---|---|
| `api-endpoints` | Adding routes, handlers, or controllers |

## Usage

Install via the Claude Code marketplace or point directly at this repo as a local plugin source.
